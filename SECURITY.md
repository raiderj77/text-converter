# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the production
deployment built from it.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not
open a public issue for a suspected vulnerability or include pasted text,
generated credentials, contact data, tokens, or exploit details in a public
discussion.

Include the affected URL or file, reproduction steps using synthetic data,
expected impact, and any suggested mitigation. FlipMyCase tools are designed
to process content in the browser, so a report should call out any unexpected
transmission, logging, storage, or disclosure of tool input.

If private reporting is unavailable, use the contact method at
https://flipmycase.com/contact and include only enough information to arrange a
secure follow-up.
